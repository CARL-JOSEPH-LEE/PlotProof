<h1>PlotProof 的技术原理</h1>

<p>PlotProof 把剧情一致性检查拆成可追溯的步骤：提取明确事实、核对原文、生成候选、复核上下文、保存作者判断。它的主要价值在于把“发现问题”连接到“核对证据和继续改稿”的完整流程。</p>

<h2>一把钥匙，如何变成一条待审问题</h2>

<table>
<tr><th>输入原文</th><th>提取的事实</th><th>来源</th></tr>
<tr><td>铜钥匙被彻底熔毁。</td><td>铜钥匙 · object_state · destroyed</td><td>第二章，原段落及字符位置</td></tr>
<tr><td>他取出铜钥匙开门。</td><td>铜钥匙 · object_state · intact</td><td>第七章，原段落及字符位置</td></tr>
</table>

<p>两条事实属于同一主体、同一属性，却给出不同状态，于是形成候选。离线模式按有限规则展示候选；模型模式会进一步核对上下文。如果前文明确出现“铜钥匙被成功重铸”，它会被提取为状态变化，之前的状态分组会重置，避免把已解释的变化直接当成矛盾。</p>

<h2>逐层处理</h2>

<p>章节与段落：document.py 识别中英文章节标题及 Markdown 标题，保留规范化稿件中的行号、字符区间与章节编号。段落标识由内容摘要和重复出现次序组成。桌面编辑器把 Python 字符位置转换为 Qt 使用的 UTF-16 位置，让表情符号之前和之后的选区仍能准确对应原文。</p>

<p>事实提取：rules.py 提供保守的离线规则；engine.py 的模型流程要求结构化 JSON，包含主体、属性、取值、类别、段落标识、精确引文和是否为明确状态变化。模型由用户通过 Ollama 或兼容接口提供，项目没有训练或附带自己的大模型。</p>

<p>引文校验：每条引文必须在对应段落中完整、精确地出现一次。不存在的引文、模糊的重复引文、无效段落标识和字段格式错误都会被拒绝。这个步骤能核对引文出处，但不能证明模型给出的属性解释必然正确。</p>

<p>候选生成：按主体名称与属性归组，对照取值；明确的修复、复活等状态变化会重置相关分组。当前实现使用 Python 数据结构，按文本位置排序，不包含向量数据库或自动别名消歧。相同人物的不同名字仍可能漏掉关联。</p>

<p>上下文复核：模型模式逐对检查候选，返回“疑似问题”“已有解释”或“证据不足”。短跨度提供中间段落；跨度太长时提供两端附近的段落，并明确标记上下文不完整。只有有效的“疑似问题”进入审阅台；未得到有效复核的候选会产生提示。</p>

<p>作者判断：审阅台展示两处引文、完整段落上下文的节选、章节与行号。作者可以确认、记录解释、定位原文、修改后重检，或导出报告。</p>

<h2>为什么改稿后可以接着审</h2>

<p>疑点标识由主体与属性、两段引文以及它们之间的文本内容共同生成。修改无关结尾通常不改变这个标识，原有备注和判断可以继续使用；在两段证据之间补上剧情解释则会改变标识，使该候选重新接受判断。它是基于内容的审阅状态管理，不是只记住一条易变化的行号。</p>

<p>草稿与正式版本分开保存。保存新版本时先保留旧版本快照；恢复旧稿会创建新版本，后来的历史仍被保留。文件采用 fsync 后原子替换，保存结果时核对稿件摘要和版本号，避免把旧检查结果附到新稿上。</p>

<h2>运行效率与桌面实现</h2>

<p>事实提取按约 10,000 字符分批。缓存键包含分析版本、服务类型、接口地址、模型及批次内容；完全相同的批次可以复用已提取事实，上下文复核仍重新执行。报告记录实际请求数与服务返回的 token 用量。缓存复用取决于批次是否相同，并不意味着每次小改动都只检查一个段落。</p>

<p>界面使用 PySide6 / Qt Widgets；后台任务通过 QThread 信号传递进度与结果。QLockFile 和本地 IPC 管理桌面单实例。章节地图由 QPainter 绘制，PDF 由 Qt 文档与打印接口生成。PyInstaller 将 Python、Qt 和应用打包为 Windows 程序，无需启动浏览器。</p>

<h2>当前边界与改进方向</h2>

<p>当前每份稿件最多 30 万字符，每批最多 100 条模型事实，每次最多 120 对候选复核。达到上限或未完成复核会提示覆盖不完整。离线模式主要覆盖明确的瞳色、惯用手、血型、出生年份，以及部分物品与生死状态。</p>

<p>别名、跨批次术语归一、隐含时间关系、不可靠叙述者和复杂世界规则仍需要改进。现有测试验证程序行为、证据位置和桌面流程，不构成真实文学作品的准确率评测。最有价值的后续工作是建立可公开的真实反例集，对不同模型和规则进行可重复的质量评估。</p>
